# Mattock
Adds mattocks, a tool that is a combination of a pickaxe and an adze, to the game.

### What Are Mattocks For?
Mattocks can be used to mine blocks that are mined with a pickaxe or shovel, as well as leaves. Mining leaves does not consume durability. They can also have can be used to make path blocks like a shovel. 
All mattocks have twice the durability of other tools of the same tool material. They can be enchanted with any enchantment for pickaxes besides efficiency (this is to help keep them balanced).

### How to Get Mattocks?
Mattocks are available for all tool materials.  

Copper, iron, gold, diamond, and netherite can be crafted with two sticks and 4 of their respected material (netherite is upgraded from diamond like normal).
